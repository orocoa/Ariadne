# Ariadne 简历修复与求职能力审核

日期：2026-10-14。根据本轮工作区、实际已保存生成回执、参考版式与独立三路审核。私人原件、生成正文、附件身份及本机记录不纳入提交；本地证据保存在 `work/resume-audit-20261014/`。

## 判断

保留已有来源、Candidate/Job 分域、版本、Working/Proposal 和人工保存架构。Ariadne 的产品目标是：在同一 Codex 模型与资料条件下，减少重复说明与操作，持续理解个人资料和职位，交付可直接使用的简历，并帮助用户把能力建议转化为有证据的进步。接入 Codex 或增加 agent 数量本身不证明更好用。

当前优势是可审阅的领域记录与有界写权限。当前主要弱点是简历任务的完整上下文、连续模板/文件记忆和语义质量验收；在这些环节尚不可靠时，不能声称整体胜过直接 Codex。先完成简历成品闭环，再用同条件比较决定后续投入；无需先重写项目或扩大电脑权限。

本轮开发使用三个独立 agent：架构与产品、内容与语义、QA 与反例测试。产品自身仍是当前受限模型调用，不因这次审核而自动获得多 agent。

## 本次失败的原因与已修复范围

参考两页附件已完整传输。旧交付只允许 `kind/title/body/nodes/edges`，正文是纯文本；浏览器一律固定行数分页，无法表达参考章节层级、日期对齐和页面安排，并强制印上品牌和非确认信息说明。此处是产品实现缺陷，不应要求用户接受报告式简历。

已保存回执还显示聊天中的“已缩窄/已删除”与文档中的相关陈述不一致，审阅注记混入投递正文。模型同时生成聊天与文件、缺少简历专项约束，且当次上下文覆盖并不完整。去水印不能单独解决这类语义问题。

本轮已实施：

1. 独立 `RESUME` 数据分支，以 blocks 为唯一正文；模型按当前完整参考选择有界排版，翻译不擅自改栏目/求职方向。注记与正文分开，禁止从模板例文填造事实，必要身份/冲突无法解决时提出问题。
2. 无品牌、水印和强制核验说明的 PDF；实际绘制文字附加坐标对应的 Unicode 文本层。下载文件可复制、搜索、提取，文件名不重复加扩展名。
3. 条目/日期、项目符号、参考换页与有界分页。独立 QA 找到的长条目孤标题、短职位标题与首条正文分离已修复。
4. v1 历史、通用文件、六入口、缓存、失败与保存权限兼容。原件与确认记录不改写；旧生成正文不被后台修改，获得新版简历需要重新生成。

当前版式范围是 A4 单栏、左对齐页头/章节和条目日期右对齐。字体沿用 VI 中英栈，不承诺与任意 PDF 像素一致。照片、双栏、居中页头和任意装饰版式的忠实复刻仍有明确限制。文件文本层不是 PDF/UA 或所有招聘系统认证。

## 建议实施顺序与验收方式

**第一阶段：完整资料、依据与连续简历任务。** 增加一个有界 `ResumeTask`，关联当前 Candidate fingerprint、可选 Job revision、模板 SourceDocument/hash、完整文档版本和用户要求；每个条目带内部来源引用与事实状态，导出不印内部字段。优先读回被预算遗漏的相关材料和全文，解决职责/数字复活、模板换轮丢失、旧文档尾部丢失。界面先复用原件、详情、Working 与保存控件，不重建通用 Agent 平台。完成条件是长资料、第二页尾部、跨入口当前更正、撤回/版本冲突和普通失败都正确。

**第二阶段：同模型配对评测。** 使用相同 Candidate、Job、模板、型号和强度，对 Ariadne 与直接 Codex 比较八类任务：初稿、针对职位改稿、翻译、仅换版式、更正职责/数字、长材料/尾部、重开连续编辑、岗位能力差异与练习建议。记录事实错误、修改一致性、版式可读性、文字提取、人工补问/操作数、耗时和 tokens；时间/成本与结果质量分开判断。先用合成资料，用户授权后再选择真实案例。最好由不知道生成端的用户/独立审阅者评判，不以内部匹配分数或结构校验代替实际结果。

**第三阶段：能力练习与证据回填。** 选择一个目标岗位/能力点，给出可完成的练习及产物标准；用户提交产物后复评，明确能力、证据、表达与相关性差异。人工保存后才成为可引用的新资料。只有连续任务减少重复工作且给出可验证进步，才支持“更好用”的结论。

以上三阶段是可选择的建议，未自动实施。用户也可以只保留本轮简历 bug 修复。

- 20 组相关离线回归、VI、语法和公开文件检查；新增两组简历回归、原文件缓存/重试/回收回归通过。独立 QA 覆盖 49 个分页边界、1600 字条目/120 字右栏和 24 个连续长条目，没有漏尾、重复或孤标题。

- 真实 GPT-6.1-Sol/high 合成两页参考，经现有 App Server 一次请求，实际传输 2 张完整页面图，返回 9 个 RESUME blocks；章节/换页、12 人样本、职责更正和未知说明分离正确，proposals/card_proposals 为空、persistence=not_written。随后浏览器实际下载与视觉/提取核对通过。没有重新发送用户职业材料。
- 本机 Skill 9 文件备份更新、237 项 manifest hash 通过；后端在已有窗口中仍是旧进程，需退出重开以加载新契约。源码修复不等于已部署官网或已发布新公开包。
