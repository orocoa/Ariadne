2026-10-14。按用户批准，补齐第二阶段评测的模板版式短板，并区分格式不支持与缺事实。范围为本地源码、测试和项目记录；不 push、部署或升级已安装 Skill。

## 结果

第二阶段 C04 的同一份合成资料、自己的完整 C01 前稿和完整两页双栏模板，在修复后的生产领域路由、生成、独立审核和浏览器导出中已生成两页双栏 PDF。第一页左侧教育、右侧 Example Studio 工作，第二页右侧延续 Tail Study；事实性 blocks 的类型、正文和右侧日期与前稿逐项完全相同。跨页只重复结构性 EXPERIENCE 栏目，不填入模板例文或额外经历。合成材料很短，按既有两页要求保留空白，不制造内容填页。

本次明确的单栏表达/导出工具边界已修复。**仍不能据此证明 Ariadne 整体优于直接 Codex**；这是对已发现短板的修复验收，未重新开展整体配对评测、人类操作成本或求职效果比较。

## 实现与门禁

- 新生成的 `resume.columns` 为 null 或受控对象：左栏比例、栏间距、可选细线及与原 blocks 对应的 FULL/LEFT/RIGHT 归属。旧单栏稿继续读取。正文和依据仍唯一来自原 blocks；前后端拒绝越界、未知字段、错栏的姓名、孤栏目及错误换页。
- 渲染器先测量各栏，再组成物理页面；两栏独立换行和溢出续页，显式 PAGE_BREAK 同时推进两栏。文字层保持页眉、左栏、右栏顺序；条目日期沿所属栏右边界，保留悬挂缩进及孤标题保护。四页上限及失败不截断保留。
- 换版式允许调整旧分页，但保留实际用户明确的页数要求。独立语义审核检查真实结构；READY 后才在浏览器渲染，审核不再要求在其前已经存在最终 PDF。渲染成功、可下载和事实审核通过仍是不同阶段。
- `FORMAT_UNSUPPORTED` 专门报告实际格式限制；`NEEDS_FACTS` 只用于必要身份/事实问题；内容、引用或分页可修正问题仍是 `REVISION_REQUIRED`，运行失败沿原显式错误通道。两种阻断状态不生成新文档或下载，保留请求、模板、旧稿和恢复上下文。历史状态不自动改写。
- 完整上下文、逐字段来源、独立事实审核、来源 hash、当前 Candidate/Job、任务/文档 CAS、原领域原子保存、人工确认事实保存机制保持。六入口更新脚本缓存版本；未更换 Provider、型号或推理强度。

具体结构见[完整简历任务契约](RESUME_TASK_AND_GROUNDING.md)。
