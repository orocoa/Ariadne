# 完整简历任务、逐条依据与模板连续性

2026-10-14。用户批准第一阶段；同模型配对评测、能力练习闭环仍待选择。本契约承接[简历审核](RESUME_AND_CAREER_AUDIT_20261014.md)与[对话交付](CONVERSATION_OUTPUT_AND_STREAMING.md)。

## 当前行为

新简历使用完整当前有效的结构化个人资料、已保存补充、本对话先前真实用户原话及本轮陈述。首次建任务前的未保存更正也纳入，不靠普通聊天的短历史猜测。历史按原时间排序，标为未保存自述；问题、假设、措辞建议不能自动成为事实，AI 回答不作依据。其他对话、材料导入文本，以及与已撤回/替换/失效补充绑定的原话排除；其可见历史仍保留。普通讨论的词面选取、24 KB 资料预算和截断历史不再承担简历生成。当前完整输入上限 256,000 UTF-8 bytes、500 条证据；超限明确失败，不截断生成。完整结构化字段可能包含此前 AI 整理的 summary，并不表示所有保留原件已经完成理解；尚未分析的原件继续沿现有资料分析入口处理。

每个工作区、领域、精确对话维护一个任务。PERSONAL/JOB_OVERVIEW 使用其工作区内固定聚合会话，Candidate/Job 使用原有 conversation_id；不按全局最近简历、文件名或相似经历猜归属。Job 定制绑定当前精确有效修订全文，职位要求仅作背景，不作个人事实；职位概况不替用户选择目标。

同一任务继续修改时读取完整最新稿、真实任务原话和必要的澄清问题。缺事实与需修改的回执也保存任务 head、模板和完整要求；补充后继续，不靠聊天摘录恢复。只有审核通过的稿件形成可导出 document version。所有旧版本、原件及既有 v1/v2 历史保留；旧产物不自动变成已审核稿。底层支持指定版本读取，但本阶段未接入旧版选择/回退编辑 UI，也未接入跨对话任务选择。

## 生成与审查

原领域模型按实际人类请求选择 RESUME_INTENT；代码不使用简历关键词判断。领域输出先按原契约校验且不能顺带产生 Candidate、记忆、资料卡或 Job 修改。随后沿同一已选、已验证多模态型号和设置生成简历，再单独审核实际完整稿件、当前完整资料、真实修改要求及视觉模板。生成和审查均关闭搜索及外部工具，不把开发 Agent 或模型名称当能力资格。

每个 block 的正文与右栏分别具有 source refs；姓名、联系方式、日期、数量和职责都需要依据。事实性栏目标题也要依据，普通栏目及空字段可为结构。独立审查覆盖身份、当前更正、所要求内容完整性、模板与事实分离、翻译范围、聊天与成品一致、投递正文纯净度。所有非空事实字段受支持、七项通过且无问题时才为 READY；缺事实/冲突/失败不生成下载文件。依据可来自未另存的明确人类自述，不能来自假设、目标、职位要求或模板例文。来源可读、人工保存和模型审核都不等于外部事实核验。

新 HTTP 请求省略任务上下文也不能生成未经审查的 RESUME。普通 PDF 输出增加一次独立语义用途检查，只发送本轮真实要求、实际 PDF 文本及前稿存在/标题信息；若它实际是简历，转入完整任务生成与事实审查，检查失败则阻断文件。普通报告仍保留原通用 PDF。常规无搜索简历路径通常三个请求；缺事实时两个，普通报告 PDF 两个，误选通用 PDF 后转简历四个。实际 token 用量合并，页面进入说明披露范围和额外费用；进入本身不发送材料。

## 模板与投递文件

当前参考附件使用既有完整图片/PDF 路径及本轮同意，绑定 durable 附件 ordinal、工作区/领域/对话/请求身份与 SHA-256。历史模板复用必须通过本轮复用勾选，并绑定任务修订、模板及精确型号/参数；保存下一轮或设置/工作区变化后重置。独立 task-only resolver 校验真实 head、来源归属、字节与 hash，不放宽原 current-turn resolver，也不接受任意磁盘路径。

继续有参考模板的任务不能静默丢掉该模板；换模板可附上新文件并单独确认。当前没有独立“移除模板但原稿原样继续”动作。模板原文只决定版式，不能补写姓名、经历、指标；不支持的排版明确说明，不声称像素级还原。生成器复用现有 A4 单栏、右侧日期、细线栏目和分页，并保持可复制的中英文字层；原有四页/字段上限不放宽。品牌、水印、仅供参考、审阅注记和制作说明不进入投递 PDF。不宣称全部 ATS 或 PDF/UA 认证。

## 保存、依据与并发

新增 `resume_tasks`（CAS head）与 `resume_document_versions`（append-only）。成功领域回执、原领域动作/分析、任务 head 与文档版本在同一领域事务落盘。模型执行、传输层与读页面都不写确认事实。派发前核对完整来源/任务/可选 Job，回执后再次核对；同一写事务读入源记录与 head，旧结果不能覆盖更新。失败仍保留原 USER/失败记录及来源。

每版保存完整稿、逐字段依据、冻结来源快照、独立审查和模板绑定。`evidence_hash` 封印整个依据快照，并与原 ASSISTANT proof 交叉绑定；读取复核快照、人类文本 hash、角色/来源状态及任务原话身份。会话原话另按精确 store/record 身份与时间冻结，派发、保存和读取核对原字段；当前轮状态/AI 回复改变及其他会话的消息不造成假冲突。前稿连续性仅传完整稿与 hash，不重复整份旧证据。依据面板显示当时的实际来源字段和可用性，不按当前排序重新解释 evidence-N；内部身份不印到正文。渲染及每次缓存下载点击核对稿件、依据 proof、当前 Candidate 和可选 Job；损坏或失效结果明确失败。

## 第一阶段验收与判断

三个 agent 分别实现/审核数据架构、语义执行和独立反例测试，并交叉复核接线。离线验证覆盖长资料末尾、完整前稿、逐字段 ledger、缺事实续答、撤回/更正、模板 hash/归属/同意、HTTP 四领域边界、generic PDF 绕过、并发 CAS/原子失败、缓存下载和损坏依据。35 项相关套件全通过；新增语义运行 22 项、四领域集成 18 项和独立 core/support 全通过，完整 Skill 打包 8 项通过。JS/Python 数值指纹边界经实际 Node 4,126 个 finite wire 数对照修复，非有限数拒绝；不舍入或改写资料值。原失败日志与反例保留 `work/resume-stage1-20261014/`。

GPT-6.1-Sol/high 的三组真实合成路径均完整生成再独立审查，分别约 146 KB / 155 KB / 156 KB；后一组研究记录位于最后，12 人只在 9,365 字符 summary 的尾部、facts 为空，生成仍正确引用并保持研究职责。第三组本轮只有简历要求，20/8 撤回和贡献更正仅在建任务前的会话原话，仍正确引用先前自述，旧 assistant 的领导部署说法没有进入证据或正文。每步发送完整两页视觉模板。另一次真实审查将注入的部署职责、已撤回 20/8 数字及虚假“已移除”声明判为需修改，没有下载产物；注入 writer 是替身，不计为真实生成。两次真实用途检查分别识别 CV 和软件测试报告，未传个人证据或旧稿全文。合计十二次真实请求，全部为合成资料，没有发送用户私人资料。

egolite 在隔离工作区实测生成、保存、两页 PDF 下载、重开继续、模板复用、缺事实续答、错误回执不产生新下载；页面无错误/横向溢出。其截图接口超时后使用隔离 Chromium 对实际 DOM 和现有 CSS 补视觉检查，PDF另行提取及逐页检查。合成测试证明这些具体边界可执行，不能外推每份简历语义都正确或全面优于直接 Codex。

判断：第一阶段为可投递文件提供了完整上下文、独立事实审查、模板/最新稿连续性和保存后依据校验；必要事实不足时阻断交付。真实个人简历仍需以用户当前有效资料实际生成并核对，不能把本阶段合成数据的成功当作个人经历验证。同模型效果比较与能力提升闭环继续由用户选择。
