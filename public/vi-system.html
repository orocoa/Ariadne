08 / GOVERNANCE

体系要能检查，才能延续。

新增界面先选语义变量，再复用组件。修改基础视觉时，同时更新规范、资源和验收；不要再复制一套箭头或另配一组灰色。

  1. 改一个源

    vi/manifest.json 定义 token 与图标；由脚本生成 CSS 和 SVG。

  2. 检查新增偏差

    运行 python3 scripts/check_vi.py。既有旧样式明确登记；新硬编码颜色、图标副本和未知 token 必须修正。

  3. 看真实页面

    桌面与窄屏检查网格、中文换行、焦点、图标、加载和减少动态效果。字体用实际渲染证据核验。

本版完成核心资源接入及全 public 视觉清单。旧版绿色页面、已有专用图形和个人理解页面的局部样式记录为待迁移项，不声称已全部重构。自动检查防止已覆盖类型的偏差增加，不能代替视觉和内容验收。
